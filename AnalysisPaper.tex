\begin{abstract}
\centering
Precise timing measurements in the CMS electromagnetic calorimeter (ECAL) provide powerful discrimination against pileup and enhance sensitivity to physics signatures involving nonprompt and delayed particles.
However, the default Run~II ECAL time reconstruction, based on the ratio method, is susceptible to degradation from out-of-time pileup.
In this work, a cross-correlation (CC) timing algorithm is introduced that exploits the pileup-aware ECAL energy reconstruction to improve time determination at both the crystal and object levels.
The performance of the CC algorithm is evaluated using proton--proton collision data and simulation, employing refined timing resolution measurements and new methods to estimate approximate generator-level truth times.
Relative to the Run~II default method, the CC algorithm improves the single-crystal time resolution by approximately 30~ps.
At the object level, electron and photon time resolutions of order 100~ps are achieved, compared to typical Run~II values of approximately 300~ps.
These results demonstrate that substantially improved ECAL timing performance is achievable with the current detector, and motivate the adoption of the CC algorithm as the default ECAL timing reconstruction for Run III and future precision-timing applications.
\end{abstract}
